# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview
This repository contains Aditya Rajput's personal portfolio website. It is a static website consisting of HTML, CSS, and JavaScript.

## Project Structure
- Root: Main portfolio site (`index.html`, `style.css`, `script.js`).
- `Recreation/`: A specialized sub-project for a pixelated dashboard based on the "Build your builder's page" task from pixl YSWS.

## Development Workflow
As this is a static website, there are no build or compilation steps.
- **Run/Preview**: Open `index.html` or `Recreation/index.html` in any modern web browser.

## Architecture Notes
- **Design Goal (Recreation)**: The `Recreation/` folder is intended to be a pixel-art themed dashboard inspired by `pixl.hackclub.com`. 
- **Mentor Mode**: For the `Recreation/` project, Claude acts as a mentor/teacher, providing conceptual guidance and "how-to" explanations rather than writing the implementation code directly.
